# Battery Jesus Emulator downloads

Download the supported, tested desktop emulator:

- [macOS Apple Silicon](https://github.com/electro-and-co/battery-jesus-emulator-downloads/releases/latest/download/Battery-Jesus-Emulator-macOS-arm64.zip)
- [Linux x64](https://github.com/electro-and-co/battery-jesus-emulator-downloads/releases/latest/download/Battery-Jesus-Emulator-Linux-x64.tar.gz)

Extract the complete archive. macOS is ad-hoc signed, not notarized or Developer ID signed. Linux package tests run on Ubuntu 24.04. Windows and Intel Mac downloads are not provided.

Each installation creates its own private identity. Staff enrollment through the Main employee console is required for connected setup; Production enrollment is disabled. Never share private enrollment requests or installed profiles.

This repository contains public binary releases and download documentation only. [Release notes](https://github.com/electro-and-co/battery-jesus-emulator-downloads/releases/latest) describe the tested artifacts and platform limits.
